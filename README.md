# Capstone_1

This mini-capstone project focuses on analyzing a sales dataset for Maine to retrieve information on business-related questions. 

# Business Objective 
- Calculate revenue for given sales territory while identifying start and end sale dates
- Analyze revenue trends by year and month
- Compare territory vs Region Performance 
- Analyze customer purchasing behavior 
- Develop business recommendations 

 # Tools/ Technique 
 - SQL: Querying and analyzing the sales database.
- Excel:Creating Pivot Tables and Pivot Charts.
- GitHub: Storing project files, tracking changes, and collaborating with team members
